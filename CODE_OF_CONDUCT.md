# Code of conduct

Spotify Karaoke is for listeners of every language, and so is this project. Be kind, assume
good faith, and keep feedback about the work, not the person. Harassment, insults and
discrimination of any kind aren't welcome in issues, pull requests or anywhere else the
project lives.

The maintainer may edit or remove comments, and block people, who don't follow this. To
report a problem privately, message the maintainer on
[Discord](https://discord.com/users/370486976643727360).

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
