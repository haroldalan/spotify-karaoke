# Security

Please report security problems privately, not in a public issue: use **Report a
vulnerability** on the repository's [Security tab](https://github.com/haroldalan/spotify-karaoke/security),
or message the maintainer on [Discord](https://discord.com/users/370486976643727360).

Fixes ship in the latest version, through the Chrome Web Store, Firefox Add-ons and Edge
Add-ons. What the extension reads, stores and sends is in the
[privacy policy](PRIVACY_POLICY.md).
